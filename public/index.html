⬇️ Xuất / Nhập dữ liệu

Dữ liệu đã tự lưu trên máy chủ theo tài khoản. Xuất/Nhập chỉ để sao lưu hoặc chuyển sang tài khoản khác.

📊 Nhập sách từ file Excel / CSV
Hàng đầu của file là tên cột: Tên sách, Tác giả, Thể loại, NXB, Năm, Số trang, Giá bìa, Vị trí, ISBN, Trạng thái. Chỉ cần cột Tên sách, các cột khác có thể để trống. Tải file mẫu
